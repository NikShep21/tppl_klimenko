# Токенизатор

Программа читает исходный файл в UTF-8 и выводит токены в формате
`(тип, значение, строка:столбец)`. Позиция начала токена отсчитывается с единицы;
табуляция занимает один столбец. Пробелы, переносы строк и комментарии `#`
пропускаются.

## Запуск

```bash
python3 tokenizer/main.py input.txt
```

Для файла с содержимым `x = y * 2 + z * 3` вывод выглядит так:

```text
(IDENT, x, 1:1)
(OP, =, 1:3)
(IDENT, y, 1:5)
(OP, *, 1:7)
(INT, 2, 1:9)
(OP, +, 1:11)
(IDENT, z, 1:13)
(OP, *, 1:15)
(INT, 3, 1:17)
```

Значение токена сохраняется как в исходном тексте, включая кавычки у строк.
Вещественные числа имеют вид `12.34`, знак считается отдельным оператором.
Строки заключаются в двойные кавычки и не переходят на следующую строку.

Для `a @ b` сообщение выводится в поток ошибок, код завершения — `1`:

```text
input.txt:1:3: lexical: unexpected character '@'
```
