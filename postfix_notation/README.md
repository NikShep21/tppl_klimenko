# Стековая машина

Программа на Python 3 вычисляет выражения в постфиксной нотации.
Числа и операции разделяются пробелами; операция записывается после
операндов. Поддерживаются `+`, `-`, `*`, `/` и `~`.

Оператор `~` возвращает модуль разности двух верхних чисел. Если хотя бы
одно равно нулю, заменяет весь стек квадратом суммы всех его чисел.

## Пример входа

```text
3 0 4 ~ 2 ~
```

## Пример выхода

```text
Шаг 1: 3 -> стек: [3]
Шаг 2: 0 -> стек: [3, 0]
Шаг 3: 4 -> стек: [3, 0, 4]
Шаг 4: ~ -> стек: [49]
Шаг 5: 2 -> стек: [49, 2]
Шаг 6: ~ -> стек: [47]
3 0 4 ~ 2 ~ = 47
```

## Запуск программы

Для запуска нужен Python 3
Запуск происходит через `main.py`. Выражение передаётся аргументом
командной строки в кавычках:

```bash
python3 postfix_notation/main.py "3 0 4 ~ 2 ~"
```

Разделитель `--` позволяет явно отделить выражение от параметров программы:

```bash
python3 postfix_notation/main.py -- "-5 2 /"
```

Справка по аргументам запуска доступна через `--help`:

```bash
python3 postfix_notation/main.py --help
```

## Запуск тестов

Для тестов нужны зависимости из `requirements.txt`

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r postfix_notation/requirements.txt
```

Запуск тестов в активированном окружении:

```bash
pytest
```

Покрытие тестами:

```bash
pytest --cov=postfix_notation.main --cov-branch --cov-report=term-missing --cov-fail-under=100
```

Выход из окружения выполняется командой `deactivate`.
