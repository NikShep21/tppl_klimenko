# 1. Обработка больших данных в реальном времени

**Парадигма:** параллельная
**Язык программирования:** Rust

Система должна обрабатывать больше 3 ГБ данных в секунду, поэтому вычисления нужно выполнять параллельно на нескольких потоках или ядрах. Rust подходит из-за высокой производительности, контроля над памятью и защиты от гонок данных, что особенно важно для многопоточной системы, работающей 24/7.

# 2. Прототип ML-сервиса для прогноза погодных условий

**Парадигма:** функциональная
**Язык программирования:** Python

Главное ограничение здесь — короткий срок разработки и необходимость быстро менять алгоритмы. Python позволяет быстро писать и переделывать код, а для ML у него есть готовые библиотеки вроде scikit-learn, PyTorch, pandas и NumPy. Функциональный подход удобен тем, что этапы обработки данных можно разделить на отдельные функции и независимо заменять их.

# 3. Интерактивный UI для торгового терминала

**Парадигма:** реактивная
**Язык программирования:** TypeScript

Для веб-интерфейса естественным выбором является JavaScript, а TypeScript добавляет к нему статическую типизацию. Для большого интерфейса с 50+ связанными виджетами это особенно важно, потому что типы упрощают поддержку кода и помогают раньше находить ошибки. Реактивная парадигма подходит из-за постоянных обновлений данных из WebSocket, REST API и локальных событий, а также необходимости автоматически обновлять связанные виджеты.

# 4. Прошивка для устройства регистрации температуры

**Парадигма:** императивная
**Язык программирования:** C

Здесь важны малое потребление памяти, прямой доступ к регистрам и предсказуемое время выполнения. C позволяет работать с GPIO, ADC и UART практически без лишних накладных расходов и поддерживается почти всеми микроконтроллерами. Императивный подход подходит, потому что работа устройства состоит из чёткой последовательности команд: считать данные, обработать их, передать результат и перейти в ожидание.
